# Generative AI Research Project

## Project Overview

This repository contains organised materials for a research project on using generative AI tools.

## Folder Structure

- literature_review/: sources and notes for the literature review

- quantitative_analysis/: survey data, scripts, and analysis outputs

- qualitative_analysis/: interview materials and analysis outputs

- reports_and_drafts/: draft and final writing outputs

- admin_ethics/: project information sheets and ethics-related documents

## How to Contribute

1. Use clear file names.

2. Do not upload sensitive or identifiable participant data unless approved.

3. Write meaningful commit messages.

4. Keep analysis scripts and outputs in the correct folders.
